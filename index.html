Learning Claude, Agents & GitHub

A beginner's notebook. What I've tried, and what actually worked.

The core loop

Ask Claude for a change. Claude makes it on a branch and opens a pull request. I review it, then merge or reject. Nothing changes until I approve.

What I've practiced

  • Reviewing and merging pull requests
  • Giving feedback so Claude revises the same pull request
  • Undoing a merge with a revert

What an agent is

Four parts written down: a goal, the tools it may use, the rules it must follow, and the report it gives back.

Lessons so far

  • Start agents read-only, and let them act only after I trust them.
  • Test by hand and read the output before scheduling anything.
  • Use the right tool for the job. GitHub for files and history, Claude for recurring research.
