1. Add a `notes.md` with a daily template for what I learned about Claude.
2. Write a glossary of Git and GitHub terms in plain English.
3. Create a checklist for writing a good prompt.
4. Make a `.gitignore` file for a personal notes repo.
5. Add a `CHANGELOG.md` that tracks what changes each week.
6. Turn a list of my own goals into a simple weekly plan.
7. Summarize an article I paste in and save it as a markdown note.
8. Add a `resources.md` with links I want to learn from.
9. Rewrite the README in a friendlier or shorter style.
10. Ask Claude to review this repo and suggest one improvement.
